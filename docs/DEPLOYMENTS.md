The contracts were developed as a progressive on-chain proof and contribution infrastructure on GIWA Sepolia, covering:

- Project registration
- Version tracking
- Milestone recording
- Verification
- Contributor registration
- Reputation
- Attestation

This inventory is intended to make the project's on-chain development history easier to inspect and verify.
